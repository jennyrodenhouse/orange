# Orange - Multi-Wireframe Website

A modern, interactive website featuring three distinct wireframe designs that users can toggle between.

## Features

- **Three Unique Wireframes**: Toggle between different design layouts
- **Interactive Navigation**: Smooth transitions between wireframes
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Custom Typography**: Uses Google's Jacquard 12 font
- **Image Integration**: High-quality images from Figma

## Files

- `index.html` - Main HTML page with all wireframes and navigation
- `styles.css` - Complete stylesheet for all wireframes
- `all-wireframes.html` - Combined wireframes with navigation
- `wireframe-1.html` - Individual wireframe 1 (background image + text)
- `wireframe-2.html` - Individual wireframe 2 (solid color + text)
- `wireframe-3.html` - Individual wireframe 3 (multiple images + text)
- `wireframe-styles.css` - Consolidated styles for wireframes

## Wireframe Designs

1. **Wireframe 1**: Large background image with prominent text overlay
2. **Wireframe 2**: Minimalist design with brown background (#575039)
3. **Wireframe 3**: Multiple elements including small image, vector graphic, and text

## Deployment

This website is configured for automatic deployment via GitHub Pages using GitHub Actions.

**Public URL**: `https://jennyrodenhouse.github.io/orange/`

To deploy:
1. Merge changes to main/master branch
2. Enable GitHub Pages in repository settings
3. Select "GitHub Actions" as the source
4. The workflow will automatically deploy your site
