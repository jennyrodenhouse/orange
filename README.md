# My Website

A simple, clean website template ready for customization.

## Files

- `index.html` - Main HTML page
- `styles.css` - Stylesheet for the website

## Usage

Open `index.html` in a web browser to view the website locally, or deploy to a web hosting service for public access.

## Deployment

This website can be deployed using:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
